# Assignment 4 - Heap Data Structures: Implementation, Analysis, and Applications

## Overview
This assignment focuses on understanding heap data structures and their applications in sorting and priority queues. It includes:

- Heapsort implementation
- Time and space complexity analysis
- Comparison with QuickSort and Merge Sort
- Priority Queue implementation using binary heap
- Task scheduling simulation

---

## Files in Repository

- `heapsort.py` → Heapsort implementation
- `sorting_comparison.py` → Performance comparison with QuickSort and Merge Sort
- `priority_queue.py` → Binary heap based priority queue
- `scheduler.py` → Task scheduling simulation
- `report.docx` → Detailed report
